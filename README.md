## 무엇을 하는 게임인가

**뽑고 → 키우고 → 내보낸다.** 그 위에 다섯 갈래의 콘텐츠가 있습니다.

| 콘텐츠 | 무엇을 하나 | 주는 것 |
|---|---|---|
| **격납고** | 기체를 고르고 파츠를 끼우고 레벨·스킬을 올린다 | — |
| **뽑기** | 코어 캡슐 / 크레딧 캡슐 두 창구 | 기체 · 파츠 · 재화 |
| **대전** | 자동 전투. 상대는 **내 성적(레이팅)** 에 맞춰 온다 | 크레딧 · 순위 |
| **파견** | 토벌(등급을 골라 사냥) · 원정(내보내 두고 시간으로 받는다) | 스크랩 · 파츠 · 코어 |
| **점령** | 서버에 하나뿐인 12칸 지도. 방어선을 **연속으로** 뚫는다 | 시간당 수입 |

### 알아 둘 규칙 셋

- **한 번에 데려가는 기체는 2기뿐입니다.** 그중 하나가 선봉으로 나섭니다.
- **피로도가 이 게임에서 가장 무겁습니다.** 전투마다 쌓이고 쌓인 만큼 최대 내구가 줄어듭니다
  (실측: 피로 0 에서 37% 인 판이 45 에서 3.4% 가 됩니다). **두 기를 번갈아 써야 합니다.**
- **파츠에는 대가가 붙습니다.** 올려 주는 값과 함께 반드시 깎는 값이 있어, 이점만 있는 파츠는 없습니다.

### 서버가 정하는 것

뽑기 결과, 전투 상대·시드·승패·보상, 장착·강화·레벨업·정비의 비용과 가능 여부,
점령전 판정, 스킬 강화 성공 여부 — **전부 서버가 정합니다.** 클라가 보낸 결과는 받지 않습니다.
피로도 회복도 서버 시각으로만 계산합니다(기기 시계를 돌려도 소용없습니다).

그래서 **게임 조작은 온라인 전용**입니다. 오프라인에서는 보기와 연습 대전만 됩니다.

## 실행 방법

### 그냥 해 보기
https://rowar.hun7539.workers.dev — 설치할 것이 없습니다.

### 개발 환경

```bash
git clone https://github.com/mainru99/world_of_mechaa.git
cd world_of_mechaa
npm install
npx wrangler login          # PC 마다 한 번
npm run dev                 # 빌드 + wrangler dev (http://localhost:8787)
```

배포는 **반드시 `npm run deploy`** 로 합니다. `npx wrangler deploy` 를 직접 부르면
`dist/` 빌드를 건너뛰어 고친 파일이 안 올라갑니다.

> 화면만 볼 때는 `python -m http.server 8123` 으로도 열리지만, 서버가 없으므로 조작이 잠깁니다.
> ES 모듈이라 `index.html` 을 `file://` 로 직접 열면 브라우저가 import 를 막습니다.

## 기체 — SD 픽셀아트 30종 · 5등급

(`assets/*.png`, 등급마다 6기)

  기존 세트 10기는 아래와 같으며, 추가된 20기는 [세트 02](#추가-기체--세트-02)와 [세트 03](#추가-기체--세트-03)에 정리했습니다.

  | 등급 | 기체 | 성향 |
  |------|------|------|
  | 커먼 `C` | **MULE** / **DUNE** | 워커(맷집) / 트루퍼(견제) |
  | 언커먼 `UC` | **RANGER** / **VANGUARD** | 마크스맨(방어 무시) / 헤비(대폭격) |
  | 레어 `R` | **AZURE** / **GLACIER** | 스트라이커(3연격) / 가디언(방어 무시 강타) |
  | 유니크 `UQ` | **WRAITH** / **ORACLE** | 리퍼(흡혈) / 시어(확정 치명타 3연사) |
  | 에픽 `EP` | **SERAPH** / **NEMESIS** | 아크엔젤(방어 무시+흡혈) / 오버로드(방어 무시 3연폭) |

  - 30기 모두 **440×420 공통 투명 캔버스**를 사용합니다. 세트 02와 03도 배경·바닥 그림자·관절 사이 배경을 제거하고, 원본 색과 기체 내부 음영을 보존해 발끝을 **y=408**로 맞췄습니다.
  - 등급은 카드 테두리·배지·스프라이트 배경 색으로 구분됩니다.
  - **성장률은 등급이 낮을수록 유리하게** 잡아, 레벨을 올릴수록 등급 격차가 좁혀집니다(아래 수치는 기존 세트 10기 기준):

    | 레벨 | 커먼→언커먼 | 언커먼→레어 | 레어→유니크 | 유니크→에픽 |
    |---|---|---|---|---|
    | Lv.1 | 14.1% | 17.9% | 14.6% | 20.2% |
    | Lv.20 | 6.8% | 8.2% | 7.3% | 9.1% |
    | **Lv.45** | **5.2%** | **5.8%** | **5.3%** | **5.8%** |

    Lv.45 커먼 ≈ Lv.42 언커먼 수준(파츠 없음 기준). 등급은 여전히 우위지만 격차가 '한 판 차이'로 줄어듭니다.
- **뽑기(가챠)**: 코어 1개로 1회, 10연차, 확률 공개. 파츠만 쏟아지지 않도록 결과를 5종으로 나눴습니다

  | 결과 | 확률 | 내용 |
  |---|---|---|
  | 파츠 | 45% | 장착·강화용 |
  | 크레딧 | 22% | `140 + 평균레벨×12 + 0~90` |
  | 꽝 | 19.5% | 아무것도 없음 |
  | 로봇 | 12% | 등급 추첨(커먼 5.27% … **에픽 0.367%**), 중복이면 분해 |
  | 코어 | 1.5% | 뽑기를 한 번 더 |

  - 중복 로봇은 **등급에 비례해** 크레딧·스크랩·코어로 분해
- **시작 상태**: 커먼 1기, **Lv.1**. 나머지 29기는 **뽑기로만** 얻습니다.
- **격납고 육성**: 두 갈래로 레벨을 올립니다
  - **경험치** — 대전에 출전한 기체가 획득(`승리 26+적Lv×9`, 패배는 35%). 다 차면 자동 레벨업
  - **크레딧** — `크레딧으로 즉시 레벨업` 버튼으로 1레벨 즉시 구매(진행 중이던 경험치는 소모)
  - 파츠 4슬롯(무장/프레임/부스터/코어) 장착, 파츠 강화(스크랩)
- **피로도 / 정비**: 대전할 때마다 기체에 피로가 쌓입니다
  - 피로도 1당 **최대 내구(체력) 1%** 감소. 승리 +3~5, 패배 +7~10, 상한 45
  - 격납고에서 줄어든 만큼이 **내구 바에 붉게** 겹쳐 보입니다(로스터 카드에도 `피로 19` 표시)
  - **정비 단가는 등급 비례** — 피로도 1당 커먼 3 / 언커먼 5 / 레어 8 / 유니크 11 / 에픽 15 크레딧 (레벨당 +3%)
  - Lv.45에서 피로도 30일 때: 커먼 212 · 언커먼 353 · 레어 564 · 유니크 776 · **에픽 1,058** 크레딧
  - 즉 상위 등급은 강한 대신 **유지비가 5배** 듭니다. 하위 등급을 굴릴 이유가 여기서 한 번 더 생깁니다
- **자동 대전**: 상대 찾기 → 매칭 → 시드 기반 **결정적 시뮬레이션**을 애니메이션으로 재생
  - 속도(SPD) 기반 행동 순서(ATB), 치명타·회피, SP 충전 시 스킬 발동, HP/SP 바, 전투 로그
  - 스킬 효과는 `ROBOT_TYPES[].skill.fx` 로 기술(`mult` / `hits` / `ignoreDef` / `noMiss` / `alwaysCrit` / `drain`)
  - **치명타 ×1.6**, **`ignoreDef` 는 방어력 60% 관통**(완전 무시 아님) — 한 방에 6배가 터지던 문제를 잡았습니다
  - **공격력 전역 배율 `ATK_SCALE = 0.2`** — 한 판이 너무 빨리 끝나서 전 기체·전 파츠 공격력을 1/5로 낮췄습니다.
    한쪽이 주고받는 공격 횟수(파츠 없음, 25판 평균):

    | 맞대결 | 예전(×1) | `0.33` | **현재 `0.2`** |
    |---|---|---|---|
    | MULE vs DUNE Lv.1 | 9 | 26 | **42** |
    | AZURE vs GLACIER Lv.20 | 13 | 39 | **63** |
    | SERAPH vs NEMESIS Lv.45 | 17 | 50 | **82** |

    길어진 만큼 재생 템포를 줄이고 **기본 속도를 x2**, 속도 버튼을 x1/x2/x4/x8로 바꿨습니다
    (Lv.20 한 판 = x2에서 약 32초, x8에서 8초). 더 짧게 하려면 `ATK_SCALE` 하나만 올리면 됩니다.
  - 아레나에서는 **내 기체가 오른쪽, 상대가 왼쪽을 보도록** 좌우 반전해 서로 마주보게 합니다
    (원본 그림 30장은 전부 왼쪽 향. `js/sprites.js` 의 `FACE_RIGHT` 로 예외 지정 가능)
  - 재생 도중 다른 화면으로 나가면 전투는 보상 없이 조용히 취소됩니다
  - 상대는 **내가 가진 최고 등급보다 한 단계 위까지만** 매칭됩니다
- **파밍/경제**: 승리 시 크레딧·스크랩·코어·파츠 획득 → 육성/뽑기에 재투자
  - 대전 파츠 드랍은 **승리 시 9%** (예전 35%의 약 1/4). 잡템이 쌓이는 문제를 줄였습니다
- **재화 툴팁**: 상단 크레딧/코어/스크랩 아이콘에 커서를 올리면 이름과 용도가 뜹니다
- **저장**: localStorage 자동 저장, 초기화 버튼

## 핵심 설계 메모

- **전투 = 시드 기반 결정적 시뮬레이션 → 이벤트 목록 → 재생.**
  서버가 결과를 확정하고 시드를 내려보내면, 클라는 **같은 시드로 같은 함수를 돌려 재생만** 합니다.
  그래서 화면에 보이는 전투와 확정된 결과가 갈릴 수 없습니다.
- **상대는 내 장비가 아니라 내 성적을 따라옵니다.** 예전에는 내가 낀 파츠를 그대로 따라가서
  좋은 파츠를 껴도 이득이 즉시 상쇄됐습니다(실제로 파츠를 낄수록 졌습니다).
  지금은 레이팅에 맞춥니다 — 좋은 파츠를 끼면 한동안 이기고, 그만큼 순위가 올라 다시 팽팽해집니다.
- **점령전은 져도 성과가 남습니다.** 깎아 둔 방어선이 그대로 남아 며칠에 걸쳐 큰 칸을 공략합니다.
- **요청 수가 곧 한도입니다.** D1 무료 한도가 읽은 행·쓴 행 기준이고 Workers 는 하루 10만 요청이라,
  화면에 필요한 값은 되도록 이미 받아 둔 것으로 계산합니다(하단 티커가 그 예입니다).

## 밸런스를 고치려면

수치는 전부 [`data/balance.js`](data/balance.js) 안에 있습니다.
**무엇을 만지면 무엇이 움직이는지, 고친 뒤 무엇으로 재는지는 [`BALANCE.md`](BALANCE.md) 에 있습니다.**

가장 큰 손잡이만 추리면:

| 값 | 움직이는 것 |
|---|---|
| `ATK_SCALE` | 한 판의 길이 |
| `ROBOT_TYPES[].grow` | 레벨 1 차이의 무게 |
| `PART_LV` | 파츠가 몬스터에게 얹어 주는 레벨 |
| `RATING_GEAR` | 아레나 상대의 장비 |
| `FAT_MAX` · `FAT_RECOVER_*` | 연전의 대가 |
| `SKILL_UP` | 스킬 강화 확률·비용·위력 |
| `TERRITORY[]` | 지도 12칸의 난이도·해금·수입 |

> 고쳤으면 `node tools/verify.mjs` 와 `node tools/terrcheck.mjs` 를 돌립니다.
> 며칠치 플레이가 어떻게 달라지는지는 `node tools/play.mjs 30 5` 로 봅니다.

## 저장본과 계정

진행 상황은 **서버에 저장됩니다.** 브라우저의 `rowar.save.v2` 는 화면을 빨리 그리기 위한
사본일 뿐이고, 접속하면 서버 값을 정본으로 따릅니다.

- **게스트 계정** — 회원가입 없이 바로 시작합니다. 다만 이 브라우저에만 묶여 있어,
  브라우저 데이터를 지우거나 다른 기기로 가면 되찾을 수 없습니다.
- **정식 계정** — 아이디·비밀번호를 붙이면 지금 진행 상황을 그대로 가지고 갑니다.
  새 계정을 만드는 것이 아니라 **쓰던 계정에 로그인 수단을 붙이는 것**입니다.

## 대전 전용 몬스터 10종

`Downloads/enemy`의 개별 이미지 10장을 사용합니다. 원본 색상과 내부 음영은 보존하고 배경과 바닥 그림자를 제거했습니다. 기존 기체와 같은 440×420 투명 캔버스와 발끝 y=408 기준에 맞추고, 종별 비율을 유지했습니다.

상대 찾기에서 40% 확률로 몬스터, 60% 확률로 기존 로봇이 매칭됩니다. 몬스터의 위험도는 기존 C~EP 등급에 대응하며 보유 기체의 최고 등급보다 한 단계 위까지만 출현합니다. 레벨은 출전 기체 ±2(1~60), 스탯은 같은 등급 기체를 기준으로 무작위 생성한 고정값이며 파츠는 장착하지 않습니다. 보상은 기존 대전과 동일합니다.

몬스터는 `MONSTER_TYPES`에만 등록되며 **뽑기, 시작 기체, 격납고, 소유 목록, 기체 획득 보상에 포함되지 않습니다.** 저장 키와 기존 로봇 30종의 데이터는 유지합니다.
