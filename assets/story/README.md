# 대사 삽화 — 넣는 곳

**아직 한 장도 없다.** 자리만 뚫어 뒀다(2026-09-17).
없으면 화면이 그림 칸을 **통째로 접는다** — 깨진 이미지가 뜨지 않는다.
여기에 파일을 넣는 순간부터 저절로 펴진다. **코드는 한 줄도 안 바뀐다.**

## 규격

| | |
|---|---|
| 형식 | `.webp` (`data/story.js` 의 `ART_EXT`) |
| 이름 | `<삽화키>.webp` — 아래 목록 그대로 |
| 크기 | 가로 **1200px 안팎** 권장. 화면에서 `max-height: 38vh` 로 줄여 쓴다 |
| 비율 | **가로로 긴 쪽**(16:9 ~ 3:2). 세로로 길면 대사창이 화면 밖으로 밀린다 |
| 배경 | 불투명해도 된다. 투명이면 지형 배경이 비친다 |
