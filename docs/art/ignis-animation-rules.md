# Ignis 대기모션 제작 기준

이 문서는 사용자 지시를 이어서 작업할 때 잊지 않기 위한 기록이다.
최종 갱신: 2026-09-13. 원본의 형태와 완성도가 프레임 수·동작 크기보다 우선한다.

## 원본과 그림

- 유일한 기체 그림 원본은 `assets/ignis.png`다. 440×420 RGBA,
  SHA-256 `4c855bde3487788b1ed423e50674ab2b2dbefbe60f95b677605a30fc1c8a052c`.
- 머리·장갑·날개·무기·비율·방향·기본 포즈를 다시 그리거나 재해석하지 않는다.
- 원본 픽셀을 그대로 복사한다. 회전·뒤틀기·늘이기·보간 때문에 내부 픽셀 묶음이나
  외곽선이 프레임마다 바뀌는 결과는 허용하지 않는다. 최근접 보간도 이 문제에서 자유롭지 않다.
- 허용한 발광 변화는 기존 날개의 주황·금색 계열에 한정하고 몸체를 덮지 않는다.
  새로운 배경·바닥·그림자·큰 효과를 넣지 않는다. 투명 배경은 실제 알파다.
- 모든 프레임은 같은 캔버스·크기·가로 중심축을 사용한다. 전체 움직임은 작은 수직 부유다.
  부품을 움직일 때도 원본 모양을 유지하는 최소 범위로 제한한다.

## 움직임 참고 자료

사용자가 제공한 `cdfaefe9-8995-4504-bb60-9982a5f7dd6d.zip`의 GIF는
640×360, 36프레임, 3초 반복이다. **배경이 아니라 움직임과 형태를 보라**는 요청이다.
차분한 시작, 작은 부유, 강해지는 날개 발광, 미세한 날개 끝/발 움직임을 참고한다.
GIF 자체의 갑옷 재해석·흐려짐·너비/좌우 흔들림은 따라 하지 않는다.
참고 GIF 프레임을 게임의 기체 이미지로 가져오지 않는다.

## 검수와 적용

- 시작·정점 몇 장을 보는 것만으로 완료 판단하지 않는다. 36장 전체와 모든 인접 전환,
  마지막→처음 전환을 확인한다. 밝은 배경·어두운 배경에서 관절과 외곽선을 확대한다.
- 고정 몸체만 검사해 통과시키지 않는다. 움직이는 부품, 절단선 바로 옆, 노출되는 윤곽,
  발끝까지 픽셀 누락·중복 외곽·반투명 구멍·떨림을 확인한다.
- 원본 좌표 추적, 알파 검사, 무손실 디코딩 검사는 각각 그 범위만 증명한다.
  파일이 정상 디코딩된다는 사실을 시각적 완성도의 증거로 대신하지 않는다.
- 10프레임과 비교한다. 사용자는 10프레임의 안정성을 관절 36프레임보다 높게 평가했다.
- 게임에서는 `.hg-stage .hg-hero`의 큰 기체에만 모션을 쓴다.
  선봉·보유 카드·뽑기 결과·대전은 원본 정지 PNG를 쓴다.
- 2026-09-13 기준 운영은 승인된 10프레임으로 복구했다. 새 후보는 검토용이며
  운영 적용 완료와 후보 제작 완료를 구분해 기록한다. 파츠 개편 배포 보류도 유지한다.
