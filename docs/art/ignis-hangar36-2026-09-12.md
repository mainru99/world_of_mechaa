# IGNIS — 격납고 전용 36프레임 대기모션

> 후속 정정: 사용자가 중간 프레임 깨짐을 보고하여 이 관절 36프레임의 품질 승인을 보류했다.
> 아래 내용은 당시 검수·배포 이력이며 현재 품질 보증이 아니다. 승인된 10프레임으로 운영 복구한다.

사용자가 승인한 강화 발광에 양쪽 날개·종아리 움직임을 추가했다.
게임의 `.hg-stage .hg-hero`만 애니메이션을 명시적으로 선택하며,
선봉·보유 기체·뽑기 결과·대전의 `sprite()` 기본 호출은 원본 PNG를 사용한다.

## 에셋과 재현

- `assets/motions/ignis-idle-36f-articulated.webp`: 440×420 RGBA, 36프레임,
  3,000ms 무한 반복, 무손실 WebP, 5,352,770 bytes.
- SHA-256: `b1f1ee096fda680c403571afc8a0517c64e49b11f868b15b31e9f69ebaa444fc`.
- 원본 `assets/ignis.png`의 SHA-256:
  `4c855bde3487788b1ed423e50674ab2b2dbefbe60f95b677605a30fc1c8a052c`.
- 원본과 승인된 10프레임 파일은 보존했다. 생성형 이미지나 새 그림은 사용하지 않았다.
- `python tools/build_ignis_idle_articulated.py`로 재현한다. Python 3 + Pillow 필요.
  출력은 무시되는 `dist/art-review/ignis-idle-36-articulated/`에 생성된다.
  `--source`와 `--out`으로 경로를 지정할 수 있다.
- 도구는 WebP, 개별 PNG 36개, 투명 6×6 시트, 마스크, 밝은/어두운 검수 패널,
  프레임별 수치 및 무손실 디코딩 검증 결과를 생성한다.
- 수치/해시는 함께 커밋한 `ignis-idle-36f-articulated.json`에 기록했다.

## 동작

- 몸체 전체는 정수 y좌표로 최대 10px 부유한다.
- 우측 날개는 최대 -1.8°, 좌측은 +2.0°의 작은 관절 변형을 적용한다.
  끝부분은 각각 최대 4px·3px 움직인다.
- 양쪽 종아리는 최대 2.6° 안쪽으로 기울고 발끝은 최대 4px 움직인다.
  상승하면서 날개가 펼쳐지고 발끝이 모이며, 하강하면서 원래 자세로 돌아온다.
- 원본에서 분리한 부위를 최근접 픽셀 선택으로 옮긴다. 회전에 따른 픽셀 재배치는
  있지만 보간·블러·색 번짐·다시 그리기는 없다. 절단선과 관절의 영향은 0에서 시작해
  완만히 커지며, 고정 몸체를 마지막에 합성해 연결부의 틈과 이중 실루엣을 막는다.
- 승인된 금색 발광·정점 섬광을 유지했다. 효과는 날개 패널과 주변 3px의 불연속
  픽셀 링에 한정한다. 배경·바닥·그림자는 없다.

## 화면 연결

`sprite(id, faceRight, {idle:true})`가 모션 선택 방식이다. 이 옵션을 주는 게임 호출은
큰 `.hg-hero` 한 곳뿐이다. 다른 기체에 이 옵션을 주어도 해당 모션이 없으면 PNG다.
작은 카드와 대전에는 `<picture>`·WebP 소스가 없으며 원래 좌우 반전을 유지한다.

애니메이션 미리 읽기를 없애고 PNG만 미리 읽는다. WebP는 큰 격납고에서 필요할 때
받는다. HTML → game.js → sprites.js → WebP의 캐시 태그는 `20260912-hangar36`이다.
모션 축소 설정·WebP 미지원·로드 실패 시 큰 격납고도 원본 PNG를 사용한다.

## 검수

- 36프레임 디코딩, 프레임별 83/83/84ms, 합계 3초, 무한 반복 확인.
- WebP 재디코딩 후 보이는 RGBA 픽셀 및 알파 차이 0.
- 고정 외장 56,843픽셀 및 관절 고정 영역 5,231픽셀 검증.
  머리·몸통·팔·무기 등 고정 부위의 비발광 픽셀 차이 0.
- 첫 프레임은 원본과 동일. 마지막→첫 프레임의 위치 차이는 0,
  최대 RGBA 채널 차이는 2이므로 자연스럽게 연결된다.
- 모든 프레임 캔버스 테두리는 투명. 원본 파일 해시 유지.
- 양쪽 날개 허브·어깨·무릎을 3배 최근접 확대해 독립 검수했다.
  새 틈·이중 윤곽·절단 균열을 발견하지 못했다.
- 개발/릴리즈 각각 86개 기본 렌더링 경우가 PNG, 미리 읽기 43개도 PNG임을 확인.
  큰 격납고 opt-in 1곳, 캐시 연결, JS 문법 및 공백 검사 통과.
- 릴리즈용 실제 sprites.js와 CSS를 사용하는 로컬 검수 화면에서 대형 WebP와
  카드/대전 PNG 선택·크기·반전, 정적 소스 선택, 의도적인 WebP 404 후 PNG 복구 확인.
  이번 브라우저는 모션 축소=false여서 기본 상태에서 WebP를 선택했다.
  모션 축소 경로는 검수 버튼의 source media 변경으로 확인했다.
- 초기 검수 화면에서 정지 PNG가 일시적으로 표시되지 않았으나 서버 HTTP 200과
  원본 해시가 정상이었고, 다시 렌더링한 뒤 모든 이미지가 정상 로드됐다.
- Ignis 보유 계정의 운영 플레이와 전투 실행은 이 검수에 포함하지 않는다.
