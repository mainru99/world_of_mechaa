# 이그니스 레인 · 전용 도트 공격 연출

2026-09-13 시작, 2026-09-14 로컬 구현 및 검수.

이그니스의 스킬 타격 때 몸통을 앞으로 밀던 동작을 사선 불비로 바꾼다.
날개 주변에 작은 불씨가 모인 뒤 기존 5회 타격마다 3개의 불꽃 탄이 시차를 두고 내려온다.
타격 지점에 작은 금빛 불꽃과 잔불이 남는다. 회피한 탄은 계속 지나가며 접촉 폭발을 만들지 않는다.

## 파일과 실행

- `assets/effects/ignis-rain-atlas.png`: 실제 알파가 있는 RGBA 1254×1254, 2×2 효과 아틀라스.
  좌상단 탄체, 우상단 접촉, 좌하단 잔광, 우하단 잔불. 생성 원본을 그대로 보관한다.
- `js/ignis-rain.js`: Canvas 효과. 정수 좌표·최근접 샘플링, 논리 픽셀당 화면 2px.
- `js/game.js`: Ignis 스킬 직후의 최대 5회 타격 이벤트만 연결한다.
- `docs/art/ignis-rain-preview.html`: 재생·타임라인·좌우 전환·회피·배속을 보는 검수 화면.

저장소에서 `python -m http.server 8802 --bind 127.0.0.1`을 실행한 뒤
`http://127.0.0.1:8802/docs/art/ignis-rain-preview.html`을 열 수 있다.
미리보기는 실제 효과 모듈을 사용하며 가상의 타격 번호를 표시한다. 전투 결과를 계산하지 않는다.

## 보존한 동작

- 스킬의 공격력·방어 관통·확정 치명타·5회 타격·회피/KO 판정을 바꾸지 않았다.
- 서버와 `data/balance.js`, `js/sim.js`, `js/stats.js`는 수정하지 않았다.
- 전투 기체는 원본 PNG다. 격납고 대기모션 연결은 그대로다.
- 일반 공격과 다른 기체 스킬의 기존 연출을 유지한다.
- 아군은 우하향, 적군은 좌하향으로 적의 위치를 향해 내린다.
- 화면 이탈·아레나 교체 뒤 이전 재생이 HP나 결과를 쓰지 않으며 효과와 타이머를 정리한다.
- 이미지/Canvas 실패가 전투 진행을 막지 않는다. 효과 이미지는 전투 시작에 읽기 시작한다.

## 검수와 한계

`node tools/check_ignis_rain_integration.mjs` 및
`node tools/check_ignis_rain_renderer.mjs` 통과.
실제 시뮬레이션 이벤트 12열, 양방향, 회피, 일반 공격 복귀, 조기 처치, 배속, 화면 이탈을 검사했다.
브라우저에서 실제 효과 모듈의 재생 완료, 도달·접촉·잔불 중간 장면, 역방향과 390px 너비를 확인했다.

효과가 체력 바 영역을 덮지 않게 잘라낸다. 모션 축소 환경에는 작은 잔불 표시만 남기며,
4/8배속에는 각 타격의 주 탄체만 표시하고 흰 접촉 중심을 억제한다.
8배속은 이동 시간이 13.75ms라 화면 주사율에 따라 비행보다 타격·잔불 위주로 보인다.

생성 PNG는 실제 투명 배경이지만 일부 가장자리에 반투명 픽셀이 있다.
게임에서는 고정 도트 격자에 보간 없이 그린다. 원본이 이진 알파 또는 정확한 8색이라고 주장하지 않는다.
후속 생성 2장은 가짜 체크무늬 배경이 들어가 사용하지 않았으며, 실제 알파를 확인한 첫 원본을 선택했다.
생성 모드·프롬프트는 `ignis-rain-prompts.json`, 해시·규격은 `ignis-rain-asset.json`에 기록했다.

사용자가 2026-09-14 현재 효과의 커밋·푸시·배포를 승인했다. 불비 수량은 검토한 그대로다.
더 많은 불비는 후속 개선 선호로 기록한다. 운영 결과는 별도 배포 기록에 남긴다.
운영 반영 시 파츠 개편이 들어간 main 전체를 배포하지 말고 기존 schema 12 릴리즈에 이 효과 변경만 적용한다.
