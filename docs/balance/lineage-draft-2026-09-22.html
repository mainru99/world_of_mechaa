개발 계보 · 초안

뽑을 수 있는 기체 43종(스토리 기체 제외)을 역할과 스킬이 이어지게 C → EP 로 이었다. 기체를 오래 쓰면(숙련) 화살표 끝 기체의 조각이 나오는 구조를 전제로 한다. 기체를 누르면 앞뒤 계보만 남고, 오른쪽에 잇는 이유가 뜬다. 점선은 역할 연결이 약해 다시 볼 곳.

역할이 바로 이어짐 연결 약함 — 결정 필요 갈림 다음 기체가 둘 · 합류 앞 기체가 둘

기체를 누르면 스킬과 앞뒤 연결 이유가 여기 뜬다.

갈래

초안을 보고 정할 것

  1. 약한 연결 5곳 — STATIC→SWIFT · ORBIT·ZEALOT→TYRANT 줄의 ZEALOT→TYRANT · LANCER→UMBRA · UMBRA→SOVEREIGN · GLACIER→WRAITH(갈림). 역할보다 이름 · 분위기로 이은 곳이다. 그대로 둘지, 바꿀 짝이 있는지.
  2. 갈림길(TRACER · GLACIER)에서 조각은 어느 쪽? 추천: 플레이어가 고른다 — 숙련 단계마다 번갈아 주는 방법도 있다.
  3. 숙련이 능력치도 올리나? 추천: 조각만 — 올리면 성장 곡선과 매칭이 흔들리고 오래 한 사람만 강해진다.
  4. 무엇이 숙련에 들어가나? 추천: 연습전 빼고 전부, 합동전은 두 기 모두
  5. 화면 없는 동안 추천: 서버 먼저 배포해 숙련만 조용히 쌓고, 조각은 화면이 생기면 소급 지급 — 화면 파일은 UI 개편 뒤에만 고칠 수 있다.
  6. EP 최대 숙련 보상 — 칭호만 · 칭호 + 코어 · 다른 갈래 EP 조각 중에서.
