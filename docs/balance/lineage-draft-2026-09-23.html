개발 계보 · 초안 3

뽑을 수 있는 기체 76종(스토리 4종 제외)을 C → EP 로 이었다. 세트 04(R 10) · 세트 05(UQ 18) · 세트 06(EP 5)을 넣어 가운데와 꼭대기가 넓어졌고, 같은 차체의 아종(NIMBUS · GOLIATH · HYDRA)은 같은 등급 안에서 옆으로 갈라지는 분화로 이었다. 기체를 누르면 앞뒤 계보만 남고 오른쪽에 잇는 이유가 뜬다. NEW 는 이번에 들어온 기체.
2026-09-23 사용자 결정 반영 — 갈림길은 하나를 고른다 · 합류는 앞 기체를 모두 개발해야 열린다 · 약한 연결은 끊고 그 기체는 뽑기로만 들어오는 입구 · 분화는 분화 숙련 + 합동전 공명.

다음 등급 — 숙련으로 조각 연결 약함 분화 — 같은 등급 아종 같은 차체(집안) 택1 다음 기체 중 하나를 고른다 · 모두 N 앞 기체 N종을 모두 개발해야 열린다 · 뽑기 입구 개발로는 오지 않는다

기체를 누르면 스킬과 앞뒤 연결 이유가 여기 뜬다.

갈래 — 끝의 EP 로 묶었다

아종 · 분화 — 같은 차체의 형제

한 집안은 속도 · 치명 · 회피 · 구간이 같고(차체), 무장 · 스킬 · 성장 모양이 다르다. 위 등급에서 내려오는 선은 표준형 하나로만 들어오고, 나머지는 그 등급 안에서 옆으로 연다 — 위로 올라가지 않고 옆으로 넓어지는 성장이다.

분화 — ① + ③ 으로 정했다 (2026-09-23)

① 분화 숙련

집안 표준형의 숙련을 채우면 형제 아종의 조각이 나온다(위로 가는 조각과 따로). 다 모으면 그 등급을 옆으로 '졸업'. 계보가 격자에서 벗어나는 자리.

② 개장 — 하지 않는다

뽑기 가치를 깎을 수 있어 뺐다.

③ 공명(합동전)

같은 집안 두 기를 전위 · 후위로 내면 공명 — 둘 다 공격 +8% 같은 작은 보너스. 아종을 모을 이유가 전투에서도 생긴다. 서버 규칙은 main 에서 먼저, 표시는 UI 개편 뒤.

정한 것 · 남은 것

  1. 분화 — ① 분화 숙련 + ③ 합동전 공명 결정
  2. 약한 연결 — 끊는다. 끊긴 기체는 뽑기 입구가 되어 뽑기(코어)로 얻어 계보를 탄다 결정 — PATCH→ORBIT · LENS→SWIFT · LANCER→UMBRA 셋 다 끊었다. 뽑기 입구 = ORBIT(R) · SWIFT(UC). LENS 는 다음 기체가 없는 막다른 C 기체가 됐다(숙련은 특성 포인트로만 쓰인다)
  3. 갈림길 — 다음 기체가 여럿이면 플레이어가 하나를 고른다 · 합류 — 앞 기체를 모두 개발해야 열린다 결정
  4. 숙련 → 특성 포인트 + 조각 2026-09-23 밤 · 적용 — 레벨이 오르면 특성 포인트(Lv.60 에 20)와 개발 목표 기체의 조각(Lv.60 에 14)이 함께 나온다. 목표는 계정에 하나 — 어느 기체를 키우든 그리로 모인다. 조각을 레벨에 붙인 것은 잠정이다(원래 의도는 특성 포인트뿐). 조각 수급처가 정해지면 다시 본다
  5. EP 최대 숙련 — 코어(잠정). 수량은 경제 측정 뒤
  6. EP 다섯이 들어왔다 2026-09-23 밤 · 적용 — SOLARIS · MONARCH · LIONHEART · SHOGUN · REVENANT. 기존 EP 의 앞 기체는 그대로 두고 UQ 에서 갈림길을 늘렸다(밀리 계열이 새 EP 로 간다 · RONIN 은 SHOGUN · REVENANT · AURIC 세 갈래). ATLAS 는 아직 UQ 5종이 필요하다 — 줄이려면 ATLAS 를 약화해야 해서 남겨 뒀다
  7. EP 성능을 필요한 기체 수에 맞췄다 결정 · 적용 — Lv.60 EP 안 승률: 4~5종(ATLAS · SERAPH · BEHEMOTH) 53~55% · 3종(SOVEREIGN · NEMESIS · TYRANT) 46~53% · 2종(IGNIS · AURIC) 42~46%
