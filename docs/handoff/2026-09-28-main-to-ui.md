# main → UI 브랜치 인계 · 2026-09-28 파츠 귀속

**읽기용이다.** 두 브랜치는 UI 개편이 끝날 때까지 합치지 않는다. 앞선 인계 — [09-23](2026-09-23-main-to-ui.md) · [09-25](2026-09-25-main-to-ui.md).

- 사용자 결정(2026-09-28) — **기체별 파츠 = 귀속.** 서버 · DB 까지 main 에 넣고 **스위치는 꺼 두었다**(`CONST.PART_BIND.on = false`)
- 꺼진 동안 게임은 예전과 한 줄도 다르지 않다. **켜는 것은 이 화면들이 나온 뒤, 사용자 지시로** 한다
- main 은 화면 파일(`index.html` · `style.css` · `themes/` · `js/game.js` · `js/ui/`)을 건드리지 않았다

## 1. 규칙 — 무엇이 바뀌나(켜진 뒤)

| 상황 | 규칙 |
|---|---|
| 파츠를 처음 낀다 | 그 기체에 **귀속**된다. 떼어도 그 기체 것으로 남는다 |
| 다른 기체에 귀속된 파츠를 끼려 한다 | 막힌다 — `{ ok:false, error:'part bound', boundTo: 기체uid }` |
| 귀속을 푼다 | **정제 코어 1**(`bind.unbind`). 끼고 있던 것은 낀 채로 풀린다. 풀린 파츠를 다른 기체가 끼면 그쪽에 귀속 |
| 빌드 프리셋 | **기체마다**. 저장 · 적용 · 삭제 모두 `robotUid` 가 필요하다. 적용할 때 다른 기체에 귀속된 칸은 건너뛴다 |
| 합성(3 → 1) | 재료가 서로 다른 기체에 귀속돼 있으면 막힌다(`bound mismatch`). 같은 기체면 결과가 그 귀속을 이어받는다 |
| 분해 · 일괄 분해 | 귀속과 무관하다 |
| 켜는 날 | 그때 **끼고 있는** 파츠 → 그 기체에 귀속 · 인벤토리 것은 풀린 채 · 계정 프리셋은 선봉 기체 프리셋으로 옮겨 적힌다 |

## 2. API

### `/api/state` — 밖(state 옆)에 `bind` 한 칸

```js
bind: {
  on: false,                       // 스위치. false 면 아래 규칙이 전부 꺼져 있다
  unbind: 1,                       // 귀속을 풀 때 드는 정제 코어
  parts: { '파츠uid': '기체uid' }, // 귀속된 파츠만. 꺼진 동안은 늘 비어 있다
  presets: { '기체uid': [ … ] },   // 켜졌을 때만 — 기체마다 프리셋(모양은 js/preset.js 머리말, 칸 5)
}
```

계정 프리셋 `state` 밖의 `presets`(예전 것)는 꺼진 동안 그대로 쓴다. 켜지면 `bind.presets` 를 쓴다.

### `POST /api/hangar`

| action | 켜진 뒤 달라지는 것 |
|---|---|
| `equip { robotUid, partUid, slot }` | 막히면 `error:'part bound'` + `boundTo`. 성공하면 `bound: 기체uid` |
| **`unbind { partUid }`** (새) | 성공 `{ ok, spent, rcores, uid, rev }` · 실패 `not enough rcores`(+`need` · `rcores`) · `not bound` · `bind off`(꺼져 있음) |
| `presetSave { i, robotUid, name }` | 그 기체의 프리셋에 적는다. 응답 `presets`(그 기체 것) · `robotUid` |
| `presetApply { i, robotUid }` | 그 기체의 프리셋을 적용. 응답에 `bound: [건너뛴 파츠uid]` |
| `presetDelete { i, robotUid }` | 켜진 뒤에는 **`robotUid` 가 필요하다**(꺼진 동안은 예전처럼 없어도 된다) |
| `fuse { uids }` | 막히면 `error:'bound mismatch'` |

규칙 함수(DOM 없음 · 화면이 미리 보여 줄 때 쓴다) — `js/bind.js`

```js
bindOn() · unbindCost()
equipCheck(boundRobotId, robotId)   // null 이면 낄 수 있다 — 화면은 bind.parts 로 uid 끼리 비교하면 된다
fuseBind(bounds) · presetBindFilter(rows, robotId)
```

## 3. 화면이 만들 것

1. **파츠 카드의 귀속 표시** — `bind.parts[파츠uid]` 가 있으면 '○○ 전용'(기체 이름). 다른 기체 격납고에서는 흐리게 · 장착 단추 대신 '귀속 풀기'
2. **귀속 풀기** — 정제 코어 `bind.unbind` 개 확인 창 → `unbind`. 잔액은 `/api/state` 의 `rcores`
3. **장착 목록** — 지금 기체에 낄 수 있는 것(풀린 것 · 이 기체 귀속)을 먼저, 다른 기체 귀속은 뒤에 · 처음 끼면 귀속된다는 안내를 한 번
4. **기체마다 프리셋** — 프리셋 칸을 기체 화면 안으로. 적용 뒤 `bound` 가 비어 있지 않으면 '다른 기체 전용이라 건너뛴 칸' 을 알린다
5. **합성** — 서로 다른 기체 전용 재료를 고르지 못하게(또는 `bound mismatch` 안내)
