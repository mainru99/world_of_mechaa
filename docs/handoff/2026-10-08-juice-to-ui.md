## 1. 시험 페이지 여는 법

```text
리포 루트에서: python -m http.server 5181
http://localhost:5181/proto/juice/            전투
http://localhost:5181/proto/juice/growth.html 성장(강화 · 레벨 업 · 보상 · 버튼)
http://localhost:5181/proto/juice/gacha.html  뽑기
```

- 모든 페이지에 **'지금 게임'** 모드가 있다 — 현재 게임 연출을 그대로 흉내 낸 것. 연출 켬과 번갈아 보며 비교한다
- 전투 페이지: 연출마다 **'이것만'** 단추(그 연출 하나만 켜고 재생) · `?seed=123` 같은 판 고정 · `?only=ranged` 한 연출만 켠 채 열기 · `A` 지금 게임 · `B` 전부 켬 · 스페이스 같은 판 다시
- 페이지는 `prefers-reduced-motion` 을 따른다(흔들림 0 · 섬광 없음). 화면 전체 섬광은 **0.34초 간격 제한**(광과민성 · 게임의 `flash()` 와 같은 규칙)

## 3. 연출 목록 — 게임에 넣을 때의 값

### 3-1. 전투 (`proto/juice/juice.js` · 스위치 18개)

엔진 사건을 시각표(`battleTimeline` · `TL` — `js/game.js` 와 같은 값)대로 재생한다. **세기 I** = `clamp(피해 / 최대체력 / 0.16, 0.25, 1.4)` — 작은 타격은 가볍게, 큰 타격은 무겁게(스위치 '세기 비례').

| 스위치 | 핵심 값 |
|---|---|
| 히트스톱 | `25 + 55·I` ms (+치명 40) · 격파 240ms |
| 튕겨남 · 회피 | 밀림 `8 + 30·I` px(화면 폭 960 기준) · 감쇠 진동 460ms · 피하면 비켜서며 잔상 |
| 예비 동작 | 움츠림 90ms → 돌진 60ms(부딪힘이 사건 시각과 맞게 **90ms 먼저** 시작 — 판 길이가 안 늘어난다) |
| 원거리 사격 | 11기(역할 이름으로 분류: 저격 5 · 포격 3 · 미사일 1 · 빔 1 · 개틀링 1). 겨눔 + 비행 시간만큼 **먼저 쏴서** 탄이 명중 사건 시각에 닿는다. `SHOT_T`(저격 280+110 · 포격 80+480 · 미사일 60+420 · 빔 320 · 개틀링 120+90×6) · 반동 `RECOIL` |
| 대기 모션 | 발끝 축 늘었다 줄기 4% · 흔들림 1.6° · 앞뒤 3px |
| 맞은 기체 번쩍임 | 맞은 기체만 흰 실루엣(히트스톱 동안) — 화면 전체 섬광을 대신한다 |
| 불꽃 · 파편 · 흔들림 | 불꽃 `8 + 24·I` 개 · 큰 타격엔 쇳조각 · 흔들림은 트라우마 방식(제곱) · 치명엔 확대 |
| 체력 잔상 · 피해 숫자 | 잔상 380ms 머물렀다 줄어듦 · 숫자 크기 ∝ 피해, 연달아 뜨면 위로 쌓음 |
| 스킬 예고 | 0.4초 충전(엔진 시각표의 스킬→첫 타 420ms 안에 넣는다 — 판 안 늘어남) |
| 격파 · 교대 | 폭발 · 느린 재생 0.35배 650ms · 다음 기체가 떨어져 착지 |
| 특화기술 효과 | 방벽 돔(맞으면 물결 · 다 닳으면 깨짐) · 표적 조준선 · 재밍 지직 · 수리 초록 띠 · 흡혈 붉은 빛줄기 · 관통 · 장갑 파쇄 · 처형(체력 35% 밑 마무리) |
| 스킬 종류별 색 | 스킬 데이터의 성질(`fx` 키)로 자동 분류 — 76기 전부 적용. 연타는 ×1 ×2 표시 |
| 등장 · 승리 | 시작 1.5초(입장 · VS · FIGHT) · 승리 카메라 · 패배 회색 |
| 파손 상태 | 체력 50% 밑 연기 · 25% 밑 불꽃 · **내 기체 30% 밑 화면 가장자리 붉은 박동** |

- **판 길이** — 전부 켜면 같은 판이 지금 게임 대비 **약 40% 길어진다**(대부분 히트스톱 · 격파 · 등장). 넣을 때 행동 간격(`TL.gap` 520)을 줄여 원래 길이에 맞추는 것을 사용자와 정해야 한다(아직 미정)
- 겹치는 작업 — 다른 세션이 만든 **공격 모션 엔진 `js/motion.js`**(10-07 · 화면 미연결)과 '원거리 사격' · '예비 동작'이 같은 자리를 다룬다. 넣을 때 하나로 합친다(모션 엔진 규격: `docs/art/attack-motion-spec-2026-10-07.md`)

### 3-2. 성장 (`proto/juice/growth.js` — 사용자가 "너무 좋다")

| 구역 | 연출 |
|---|---|
| 파츠 강화 | **서버 응답을 기다리는 시간 = 충전 연출**(흔들림 · 빛 모임, 최소 0.9초) → 모루 타격 · 번쩍 → 성공: 고리 · +N 튐 · 능력치 세어 올라감 / 실패: 균열 · 파편 · 회색 흔들림. 실제 확률 `enhRate` |
| 레벨 업 | 막대가 눈금마다 소리 내며 차고 넘치면 금색 → 빛기둥 · 기체 튐 · LEVEL UP · 능력치가 하나씩 세어 올라감(`computeStats`) |
| 보상 수령 | 줄이 하나씩 들어와 숫자가 세어 올라가고 재화 조각이 지갑으로 날아가 **도착할 때마다** 지갑 숫자가 오른다 |
| 버튼 | 눌림 · 물결 · 소리 · 지금 눌러야 할 버튼 맥박 |

- 서버가 느리다(조회당 ~115ms · 요청 1~1.5초) — **누르는 즉시 반응하는 연출로 기다림을 가린다**가 이 페이지의 핵심이다. 대전 출격 · 뽑기 · 강화 모두 같은 방식이 좋다

### 3-3. 뽑기 (`proto/juice/gacha.js`)

- 등급 C UC R UQ EP · 가중치는 `ROBOT_RARITY` 그대로 · 기체는 `BY_RARITY`(js/gacha.js)
- 길이 — C 약 1초 → EP 약 6초. 높을수록 오래 · 크게 · 밝게
- **캡슐 방식** — 등급별 캡슐이 떨어져 흔들리며 색이 비침(높은 등급은 낮은 색 → 진짜 색으로 바뀜: 기대감) → UQ · EP 는 어둡게 · 균열 · (EP) 줌 인 · 0.26초 정지 → 유리 파편으로 깨짐 · 충격파(화면 일그러짐) · 슬로모션
- **유성 방식(원신식)** — 등급 색 유성(EP 3줄기)이 떨어짐 · 높은 등급은 구름 소용돌이가 먼저
- 공통 — 방사선 폭발 · 마법진(기체 뒤 수직 + 바닥) · 역광 햇살 · 실루엣 → 빛이 훑으며 색 · 별 도장 · 이름 글자 떨어짐 · 레터박스(UQ · EP)
- **10연차** — 최고 등급을 먼저 풀 연출 → 10장을 낮은 등급부터 줄 세움
- **'건너뛰기' 단추가 아직 없다** — 연타할 때 답답할 수 있다. 넣을 때 같이 넣는다(사용자에게 확인)
