#### 유지한 동작

- 로그인 경험이 있는 계정의 첫 화면은 지휘실. 전투 0회 계정은 기존 전선 시작 흐름 유지.
- 점령의 비용·등급 제한·레벨 제한·보호 강행·방어선 잔여 체력·공격/보상 API는 기존 로직 사용. 오른쪽 상세에서 그대로 읽고 실행한다.
- 홈/점령 편성은 정지 PNG. `js/sprites.js`의 격납고 큰 이그니스 10프레임과 모션 감소 대체 규칙은 그대로 보존.
- 지도 조회는 요청 번호와 계정 ID를 확인한다. 다른 화면/전선으로 이동한 후 늦게 온 응답은 화면을 덮지 않는다. 캐시 재사용 시 TTL 시작을 연장하지 않는다.
- 다른 화면으로 이동하면 페이지 상단에서 시작한다. 점령→정비→복귀 시 선택 거점, 필터, 지도 확대/스크롤을 유지한다.
- 전선 진입은 홈 브리핑과 모바일 더보기에 남았다. 전선 도입 대사가 기존 전투 화면에서 실제로 시작하는 것을 확인했다.
