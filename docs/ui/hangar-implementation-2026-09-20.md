## 상태와 기존 기능 계약

- `hangarRobot()`은 `hangarUid`에 해당하는 보유 기체, 없으면 `selRobot()`을 반환한다. 기체 배열 인덱스 대신 UID로 조회 대상을 유지한다.
- `inspectRobot`/`cycleHangar`는 화면만 변경한다. `S.sel`, `S.squad`와 서버 상태를 바꾸지 않는다. 로스터 정렬은 표시 순서만 바꾼다.
- `equip`, `unequip`, `openSlot`, `openPresets`, `savePreset`, `applyPreset`, `skillUp`, `service`, `levelUp`은 조회 기체를 사용한다. 비동기 요청 전에 기체를 포착하여 응답 대기 중 다른 기체를 열어도 원래 요청한 기체에 결과가 적용된다.
- 실제 출전 편성은 기존 `openRobot` 모달의 선봉/편성/해제 흐름으로 관리한다. 전투/홈/파견/점령에서의 `selRobot()` 의미는 그대로다.
- 점령의 정비 진입은 조회 상태를 초기화하여 실제 선봉을 표시한다. 로그인 후에도 조회 기체/탭/보관함 상태를 초기화한다.
- 파츠 보관함의 필터, 정렬, 60개 단위 더 보기, 합성, 분해, 강화와 프리셋 API는 재사용한다. 필터 변경 시 펼침 상태를 유지하며 분리된 옛 DOM의 toggle 이벤트는 무시한다.
- 정보/장비/튜닝 탭은 좌우 방향키와 Home/End로 이동한다. 모바일 기본 정보 화면은 탭을 숨겨 시안 순서를 유지하고 장비/튜닝에 들어가면 돌아갈 탭을 표시한다.
- 정비/레벨업은 기존 비용과 서버 판정을 사용한다. 재화 부족/오프라인 버튼 비활성 표시를 적용한다. 스킬/파츠 강화 확률과 실패 시 재화 소모 안내를 유지한다.

## 에셋과 레이아웃

- 배경: 기존 `assets/backgrounds/hangar.webp`. 이미지 생성/수정 없음.
- 큰 기체: 기존 `sprite(type,false,{idle:true})`. 이그니스의 승인된 `ignis-idle-10f.webp`를 사용하고 기존 모션 감소용 PNG 대체를 유지한다.
- 목록/썸네일: `sprite(type,false)`의 원본 PNG. 전투 스프라이트 변경 없음.
- 1200px 초과 PC: 로스터/기체/정보 3열. 701–1200px: 기체와 정보 2열, 로스터 아래. 700px 이하: 기체→정보/장비/행동→로스터→보관함.
- 모바일은 큰 장면 높이 270px, 썸네일 스트립 숨김, 4개 능력치와 치명/회피 보조 줄, 4개 장비 칸. 원본 픽셀 비율 유지.
- 기존 scene 테마의 금색 헤더 충돌을 격납고 범위에서 청회색/적색으로 수정했다. 레거시 CSS를 제거한 단계는 아니므로 새 규칙의 적용 순서를 보존한다.

## 검수

검수 계정은 로컬 예시 데이터다. 프리뷰는 실제 DB/운영 API와 연결하지 않으며 소비 요청은 403으로 거절한다. 운영 서버에서 장비/강화를 사용한 것으로 보고하지 않는다.

- 브라우저: 1440×1000, 1024×900, 390×844, 360×800. 이미지로 열 배치, 원본 기체, 장비 슬롯, 글자 겹침을 확인했다. 1024px의 document scrollWidth 1009, 360px은 345로 페이지 가로 넘침 없음(스크롤바 제외 폭).
- IGNIS 큰 이미지 currentSrc는 승인된 10프레임 WebP, 작은 이미지는 원본 PNG임을 확인했다.
- RANGER 조회 후에도 IGNIS의 선봉 표시 유지. RANGER 장비/튜닝과 비용 표시, 무장 모달의 본인 해제/다른 기체 장착 표시 확인.
- 편성 밖 AZURE는 빈 슬롯 4개, 프리셋 모달에 AZURE 대상으로 표시. 파츠 보관함은 여분 4개, 무장 필터 후 1개이며 펼침 상태 유지.
- 모바일 장비 버튼으로 탭 표시, 장비 탭에서 ArrowRight 후 튜닝 선택과 포커스 `hv-tab-tune` 확인. 브라우저 JS 오류 로그 없음.
- `node tools/hangar-ui-check.mjs`: 8개 API 요청이 조회 UID 사용, 거절 장착 시 상태 불변, 응답 지연 중 조회 변경 시 원래 기체 갱신, 프리셋 장비 이동, 조회 UID 소멸 시 선봉 대체 통과.
- `node tools/presetcheck.mjs`: 기존 프리셋 저장/적용 및 거절 조건 검사 통과.
- `node tools/check_ignis_rain_integration.mjs`: 실제 시뮬 12개, 양쪽/빗나감/취소/배속/정지 스프라이트 검사 통과.
- `node --check js/game.js`: 통과.
- `node server/build.mjs`: 공개 항목 7개 복사 성공. `dist/themes/hangar-v2.css` 포함 확인. 빌드 산출물은 배포하지 않았다.
- `git diff --check`: 통과.
- 화면 캡처는 대화의 브라우저 도구 출력으로 검수했다. 별도 캡처 파일 없음.
