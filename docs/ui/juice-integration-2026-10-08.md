## 상태

- 사용자 지시(2026-10-08 오후): **"역할 바꾸고 성장 연출, 뽑기, 타격감까지 커밋 · 푸시 · 배포하자."** 인계서 9절의 '구현 GPT · Claude 검토'를 **구현 Claude · 아트 Codex** 로 바꿨다
- 시험 페이지 `proto/juice/` 의 연출을 게임 화면에 옮겼다. `proto/juice/` 는 import 하지 않고 고치지 않았다(비교용으로 남긴다)
- 판정 · 서버 · DB · 밸런스(`js/sim.js` · `server/` · `data/balance.js`)는 **건드리지 않았다**. 연출은 이미 정해진 결과를 받아 그리기만 한다
- 아트(등급별 캡슐 · 금 간 캡슐 · 등급 문양)는 Codex 에 맡겼으나 **이 PC 에서 Codex 의 Windows 샌드박스가 'setup refresh had errors' 로 명령을 하나도 못 돌렸다**. 사용자 결정으로 아트는 나중에 — 지금은 생성본(색만 바꾼 캡슐)이 걸려 있다. 같은 이름 · 크기로 덮으면 코드 수정 없이 바뀐다(`docs/art/gacha-art-request-2026-10-08.md`)

## 고친 파일

- `js/game.js`
  - 강화 · 스킬 강화 · 레벨 업 · 원정/점령/도감 보상 · 대전/전선/점령 결과 줄에 성장 연출
  - `doPull` — 기존 '굴림 · 열림' 0.52 + 0.7초 대기를 지우고 캡슐 공개 연출 → 결과 창. 누름 소리 `skill_charge` → `beam_charge`(9-1)
  - `playBattle` · `playJoint` — 타격감. 사건 시각표(`battleTimeline` · `TL.gap` 520)는 그대로이고, 연출 시계가 히트스톱 동안 멈추며 등장 · 격파 · 교대가 다음 사건을 민다(사용자: 길어져도 그대로)
  - `planBattleFx` — 사건열을 처음에 훑어 각 행동의 첫 타를 시각표보다 먼저 건다. 근접 90ms 전 움츠림, 원거리 = 겨눔 + 모션 엔진 준비 · 비행만큼 먼저 쏴서 닿는 순간이 명중 사건과 맞는다
- `js/motion.js` — `TIME` 을 export 만 했다(값 그대로). 공격 모션 엔진이 **처음으로 실전 화면에 연결**됐다: 종류 · 그림(아틀라스 · AZURE/KESTREL 자세)은 모션 엔진, 겨눔 · 먼저 쏘기 시각은 타격감(9절 '하나로 합친다')
- `index.html` — `themes/fx-v2.css` 연결 · `game.js?v=20261008-fx1`
- `tools/ui-preview.mjs` — `--sample-growth`(강화 · 스킬 · 레벨 업을 실제 확률 · 1.1초 지연으로 메모리에서 처리). 운영 API/DB 와 무관
- 검사 하네스 — `game.js` 함수를 VM 에서 떼어 돌리는 검사 7종에 연출 대역(`FX_STUBS` · `createBattleFx:()=>null` 등)을 넣었다. 검사 조건은 그대로. `check_ignis_rain_integration` 은 **이번 작업 전부터 깨져 있었다**(효과음 연결이 `createCombatAudio` 를 넣은 뒤) — 같이 고쳤다

## 줄인 움직임 · 안전

- `prefers-reduced-motion` — 전투 타격감은 만들지 않는다(예전 재생 그대로) · 뽑기는 곧바로 결과 판 · 성장은 입자를 줄이고 흔들림 · 섬광 없음
- 화면 전체 섬광은 0.34초 간격 제한(게임의 `flash()` 와 같은 규칙)
- 창이 가려져 `requestAnimationFrame` 이 멈추면 타이머가 대신 돌며 **실제 흐른 시간**으로 진행한다(처음엔 50ms 로 잘라 전투가 절반 속도로 흘렀다 — 고침)
- 건너뛰기 · 배속 · 화면 이탈 · 계정 교체는 예전과 같다. 연출 층은 `finally` 에서 걷힌다(캔버스 · 숫자 · 기체 스타일 · 아레나 흔들림)
