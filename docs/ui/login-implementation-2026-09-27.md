# 로그인·타이틀 화면 이관 · 2026-09-27

## 시안 적용과 현재 기능

- `Downloads/rowar_ui_rebuild/login.png`의 상단 브랜드, 큰 대표 기체, 좌측 제목·시작/계정 버튼, 하단 게임 소개 카드와 모바일 세로 구성을 옮겼다. 대표 이미지는 프로젝트의 기존 `assets/story/ch1-ignis.webp`이며 새 그림을 생성하지 않았다. 소개 카드에는 기존 `assets/backgrounds/battle-industrial-ruins.webp`를 사용한다.
- 시안에만 있는 언어 선택·전체화면·설정·가상 버전 표시는 만들지 않았다. 시작 버튼은 현재 규칙대로 첫 게스트 계정을 그때 발급한다. 계정 버튼은 인라인 로그인 폼을 열고 아이디에 초점을 준다. 가입과 계정 관리는 기존 모달에 연결했다. 기존에는 로그인 칸이 늘 노출되었지만, 타이틀 시안의 두 진입 경로를 살리기 위해 계정 버튼 뒤에 배치했다.
- `js/net.js`의 게스트/로그인/가입/로그아웃 API와 `js/game.js`의 신규 계정 전선 시작·기존 계정 지휘실 시작 규칙을 유지한다. 오프라인 시작도 유지한다. 게스트는 브라우저 데이터를 지우면 복구하기 어렵다는 안내를 시작 전에 표시한다.
- 대문이 열려 있는 동안 게임 영역에 `inert`를 적용해 보이지 않는 메뉴로 키보드 초점이 이동하지 않게 한다. 게임 진입 후 해제한다.
- 로그인이나 정식 가입 인증은 성공했으나 `/api/state` 다운로드에 실패하면 대문을 유지한다. 이때 이전 계정의 `S`를 새 계정으로 저장·동기화·주기 갱신하지 않는다. `시작하기`를 다시 누르면 상태를 재요청하고, 성공한 뒤에만 새 계정의 게임을 연다.

## 변경 위치

| 파일 | 역할 |
|---|---|
| `index.html` | 타이틀 구조, 계정 진입·인라인 로그인 폼, 연결/저장 안내 |
| `themes/login-v2.css` | 기존 이그니스 삽화의 PC/태블릿/모바일 배치, 폼·계정 모달 스타일 |
| `js/game.js` | 두 버튼과 로그인 폼, 계정 상태별 문구, 인증 후 상태 수신 실패 재시도·이전 계정 격리 |
| `tools/ui-preview.mjs` | `--sample-login` 가상 인증/계정, `--sample-login-pull-retry` 1회 상태 다운로드 실패. 둘 다 로컬 메모리 전용 |
| `tools/login-ui-check.mjs` | 상태 다운로드 실패 시 이전 계정 미저장, 재시도 후 새 계정 한 번 채택 검사 |

## 검수

- 로컬 예시 서버 `node tools/ui-preview.mjs 8813 --sample-login`에서 모바일/PC 시각 검수, 로그인 오류→재입력→성공, 게스트 시작→정식 전환, 타이틀에서 바로 가입, 로그아웃을 확인했다. 사용한 계정/비밀번호는 가상 데이터이며 운영 API·DB와 무관하다.
- 별도 예시 서버 `node tools/ui-preview.mjs 8814 --sample-login --sample-login-pull-retry`에서 인증 성공 뒤 상태 조회 503을 한 번 반환했다. 타이틀이 남고 이전 계정 상태가 표시되지 않으며, 시작 버튼 재시도 뒤 새 계정으로 진입했다.
- 1440px·1024px·390px·360px 시각 확인. 문서 가로 넘침 없음. 대문 표시/종료 시 게임 영역의 `inert` 전환과 브라우저 콘솔 오류 없음 확인. 캡처는 대화의 브라우저 도구 출력이며 별도 PNG 파일로 저장하지 않았다.
- `tools/login-ui-check.mjs` 및 전선·격납고·뽑기·대전·파견·랭킹 회귀 검사 통과. `node server/build.mjs`에 새 CSS가 포함됨을 확인했다. 실제 운영 계정의 자격 증명은 사용하지 않았다.
